# AK(3) から固定 S への経路の Lean 検証

ACC-P000024 と同じ順序付き関係子対、同じ14操作、同じ mathlib の自由簡約を使う。始点は `A = (xyxYXY, xxxYYYY)`、終点は `S = (XyyyxYYYY, xxYYYYYXyyyyy)`。上限は両端を含む経路上の最大総語長。旧共通辺は `(xYYYYXyyy, yyxxYX)` と `(xYYYYXyyy, yyxxYYYYYXyyy)` を結ぶ両向きの辺。

## 距離と確定範囲

| 総語長の上限 | 通常の最短手数 | 旧共通辺を避けた最短手数 | Lean の根拠 |
|---|---:|---:|---|
| 22 | 42 | 44 | 以前の42手の証人、今回の44手の迂回、通常の上限24と辺削除後の上限22の非交差 |
| 23–24 | 42 | 42 | ピーク23の迂回と上限24の通常グラフでの非交差 |
| 25–26 | 41 | 41 | ピーク25の迂回と、上限26での半径16＋24の通常球の非交差 |
| 27–30 | 41手の証人 | 41手の証人 | 上限30で半径8と15の球の非交差をLeanのnative計算で確認。24手以上。40手以下の排除は元のC++検査まで |

すべての自然数 h について、上限 h で41手以内に S へ届くことと h ≥ 25 が同値である。上限22の44手、23の42手、25の41手の迂回列を上記の旧共通辺の両向きで検査し、各列の長さ・正確なピーク・逆向きの列と到達も検証した。

上限22では、43手以下のどの経路も実際に旧共通辺を通ることを、経路を三分割する形で証明した。一方、上限25ではその辺を避ける41手列のほかに、35手目の操作4で同じ辺を通る41手列も再生した。上限25と26では両方とも最短である。両端を40手以内で結ぶ経路が存在するなら、ピークは少なくとも27になる。

## 二つの閉路と経路数

上限29の二つの5手列が同じ終点に着く等式は、任意の自由簡約された関係子対を始点として証明した。実例の二枝はピーク27と29で、つなげると同じ実状態に戻る10手の単純閉路になる。S 側の6手閉路では、二つの3手列（操作 ID は 3,1,3 と 2,1,2）がどちらも総語長 21→28→28→21 で同じ二つの降り先を結ぶ。その降り先同士は上限21の操作1だけでも結ばれる。したがって、この例では上限27の連結成分を越えない。上限28で S と別の終点 E₃ がつながるかは未判定である。

上限29の記録にある159状態・42層から、相異なる106,036本の41手列を構成した。34,624本はピークがちょうど29。さらに、異なる34,624本の34手の後半列それぞれに、新旧どちらの前半7手を付けても S に着くことと、得られるピークがそれぞれ27と29であることを証明した。この計数と対応付けは native 計算公理を使わない。記録した層に制限した本数は正確である。全グラフでの最短列が記録した層に尽きることは、現段階の Lean 証明の外にある。

## 検証の根拠

- 経路の上界、閉路、経路数とその集合の構成はカーネルで検証した。各定理で使った公理は検査ログに記録した。
- 非交差は、Lean で完全性を証明した探索手続きを実行し、各計算に対応する native 計算公理を使う。Lean が元の C++ のログの値を受け取って結論を出す方式ではない。
- 上限30の全下界を結ぶ定理も用意した。始点側の半径15、終点側の半径24の各保存層が許される経路を覆うこと、両保存球の非交差、始点側の最後の層から1手進めても終点側保存球に入らないこと、の各前提を与えると半径16＋24の非交差が従う。実データの先頭は、A側が深さ2までの158状態、S側が深さ3までの344状態について、保存層の被覆をカーネルで証明した。残りの層および全域の非交差が次の検証対象である。
